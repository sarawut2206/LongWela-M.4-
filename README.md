# บันทึกการมาสาย ม.4

โปรแกรมเว็บสำหรับ **ติ๊กชื่อนักเรียนที่มาสาย** แล้ว **ส่งออกเป็นไฟล์ Word (.docx)** ตามฟอร์มสรุปของโรงเรียน
โดยไม่ต้องพิมพ์ชื่อนักเรียนใหม่ทุกสัปดาห์

ทำงานในเบราว์เซอร์ล้วน ๆ — ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต ไม่ต้องมีเซิร์ฟเวอร์
(เปิดจากไฟล์ในเครื่อง หรืออัปโหลดขึ้น GitHub Pages ก็ได้)

---

## ไฟล์ในโฟลเดอร์

| ไฟล์ | หน้าที่ |
|---|---|
| `index.html` | หน้าเว็บ (เปิดไฟล์นี้เพื่อใช้งาน) |
| `app.js` | โค้ดโปรแกรมทั้งหมด รวมตัวสร้างไฟล์ Word |
| `students.js` | รายชื่อนักเรียน ม.4 (สร้างจาก `ม.4.xls` — 451 คน) |

---

## วิธีใช้งานประจำสัปดาห์ (ใช้เวลา 5–10 นาที)

1. เปิด `index.html`
2. **แถบบน** — ใส่ `สัปดาห์ที่` และเลือก `วันจันทร์ของสัปดาห์`
   ระบบจะเติมช่วงวันที่ให้อัตโนมัติ เช่น `17 – 21 สิงหาคม 2569` (แก้ข้อความเองได้)
3. เลือกช่วงเวลา **สาย 07.50 น.** หรือ **สาย 08.30 น.** (แยกข้อมูลกันคนละชุด)
4. กดเลือก **ห้อง** แล้วเปิดสมุดบันทึกมาสาย → **ติ๊กช่อง จ / อ / พ / พฤ / ศ** ของนักเรียนที่มาสาย
   - ตัวเลขแดงบนปุ่มห้อง = จำนวนคนที่ติ๊กไว้ในห้องนั้นของสัปดาห์นี้
   - คอลัมน์ **รวมสะสม** = ยอดยกมา + ทุกสัปดาห์ที่บันทึกไว้ (แถวแดง = ถึงเกณฑ์แล้ว)
   - ถ้าจำห้องไม่ได้ ใช้ช่อง **ค้นหาชื่อ** พิมพ์ชื่อได้เลย (ค้นทุกห้อง)
5. ไปแท็บ **② สรุป & พิมพ์ Word** → ตรวจตัวอย่างเอกสาร → กด
   **⬇ ดาวน์โหลด Word (.docx)** (หรือ **⬇ ทั้ง 2 ช่วงเวลา** เพื่อได้ทั้ง 07.50 และ 08.30)

ไฟล์ที่ได้จะชื่อเช่น `สรุปสาย 07.50 น. สัปดาห์ที่ 13 17-21 สิงหาคม 2569.docx`
เปิดด้วย Word แล้วสั่งพิมพ์ได้ทันที (ฟอนต์ TH SarabunPSK ขนาด/ตาราง/หัวเรื่อง/ผู้ลงนาม ตรงตามฟอร์มเดิม)

> ระบบจะใส่เฉพาะนักเรียนที่ **สาย 4 ครั้งขึ้นไป** (แก้ตัวเลขเกณฑ์ได้ที่ช่อง “เกณฑ์”)

---

## ตั้งค่าครั้งแรก (ทำครั้งเดียว)

### 1. ยอดยกมา
ถ้าเริ่มใช้กลางเทอม ให้ไปแท็บ **ยอดยกมา** แล้วใส่จำนวนครั้งสะสมเดิมของแต่ละคน
(เช่น ยอดถึงสัปดาห์ที่ 12 จากสมุด) โปรแกรมจะบวกให้อัตโนมัติ — ทำแยกกันระหว่าง 07.50 น. และ 08.30 น.

### 2. รายชื่อที่ยังไม่ครบ
ไฟล์ `ม.4.xls` ที่ให้มามี **ห้อง 1–12 รวม 451 คน** และ **ห้อง 1 มีแค่ 16 คน** — **ยังไม่มีห้อง 13**
เพิ่มได้ที่แท็บ **รายชื่อนักเรียน**:
- คัดลอกจาก Excel 3 คอลัมน์ (ห้อง / เลขที่ / ชื่อ-สกุล) มาวางในกล่องข้อความ แล้วกด **เพิ่ม/อัปเดตจากข้อความ**
- หรือพิมพ์ทีละคนในช่องด้านบน

รายชื่อที่แก้จะเก็บไว้ในเบราว์เซอร์ (กด “คืนค่ารายชื่อเริ่มต้น” เพื่อกลับไปใช้ไฟล์ `students.js`)

> **ขึ้นปีการศึกษาใหม่** ให้แทนที่รายชื่อทั้งหมดจากแท็บนี้ หรือส่งไฟล์ Excel ใหม่มาให้สร้าง `students.js` ใหม่

### 3. ชื่อผู้ลงนาม
แท็บ **ข้อมูล / สำรอง** — แก้ชื่อผู้ลงนาม / ตำแหน่ง / ระดับชั้น ที่จะพิมพ์ท้ายเอกสาร

---

## ⚠️ ข้อมูลเก็บไว้ที่ไหน

เก็บใน **เบราว์เซอร์ของเครื่องที่ใช้** (localStorage) ไม่ได้ส่งขึ้นอินเทอร์เน็ต

ดังนั้น:
- ถ้าล้างข้อมูลเบราว์เซอร์ / เปลี่ยนเครื่อง / เปลี่ยนเบราว์เซอร์ → ข้อมูลจะไม่ตามไป
- **ควรกด “⬇ สำรองข้อมูล (.json)” เก็บไฟล์ไว้เป็นระยะ** (เช่น เดือนละครั้ง) และใช้ “⬆ นำเข้าข้อมูล” เมื่อย้ายเครื่อง
- ถ้าใช้ผ่าน GitHub Pages ให้ใช้ **เบราว์เซอร์และเครื่องเดิม** เป็นหลัก

---

## วิธีขึ้น GitHub Pages

1. สร้าง repository ใหม่ใน GitHub (เช่น `late-m4`) — ตั้งเป็น Public
2. อัปโหลด 3 ไฟล์นี้ไว้ที่ root ของ repo: `index.html`, `app.js`, `students.js`
   (ไม่ต้องอัปโหลด `.xls` / `.docx` / รูปภาพ)
3. ไปที่ **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save**
4. รอสักครู่ จะได้ลิงก์ `https://<ชื่อผู้ใช้>.github.io/late-m4/` เปิดใช้ได้จากมือถือ/แท็บเล็ต/คอมพ์

> ถ้าไม่อยากขึ้น GitHub ก็ **ดับเบิลคลิก `index.html`** ในเครื่องได้เลย ใช้งานได้เหมือนกันทุกอย่าง

## หมายเหตุทางเทคนิค

- ไฟล์ `.docx` ถูกสร้างในเบราว์เซอร์เอง (เขียน OOXML + ZIP เอง) ไม่พึ่งไลบรารีภายนอก จึงใช้แบบออฟไลน์ได้
- หัวตารางจะซ้ำอัตโนมัติเมื่อรายชื่อยาวเกิน 1 หน้า
- ปุ่ม 🖨 พิมพ์ ใช้พิมพ์จากเบราว์เซอร์โดยตรงได้ ถ้าไม่อยากเปิด Word
