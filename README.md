# บันทึกการมาสาย ม.4

โปรแกรมเว็บสำหรับ **ติ๊กชื่อนักเรียนที่มาสาย** แล้ว **ส่งออกเป็นไฟล์ Word (.docx)** ตามฟอร์มสรุปของโรงเรียน
โดยไม่ต้องพิมพ์ชื่อนักเรียนใหม่ทุกสัปดาห์

ทำงานในเบราว์เซอร์ล้วน ๆ — ไม่ต้องติดตั้งอะไร ไม่ต้องต่อเน็ต ไม่ต้องมีเซิร์ฟเวอร์
(เปิดจากไฟล์ในเครื่อง หรืออัปโหลดขึ้น GitHub Pages ก็ได้)

## วิธีใช้งานประจำสัปดาห์ (ใช้เวลา 5–10 นาที)

1. เปิด `index.html`
2. **แถบบน** — ใส่ `สัปดาห์ที่` และเลือก `วันจันทร์ของสัปดาห์`
   ระบบจะเติมช่วงวันที่ให้อัตโนมัติ เช่น `17 – 21 สิงหาคม 2569` (แก้ข้อความเองได้)
3. เลือกช่วงเวลา **สาย 07.50 น.** หรือ **สาย 08.30 น.** (แยกข้อมูลกันคนละชุด)
4. กดเลือก **ห้อง** แล้วเปิดสมุดบันทึกมาสาย → กดปุ่ม **+** ตามจำนวนครั้งที่เด็กมาสายในสัปดาห์นี้
   (ไม่ต้องระบุวันแล้ว — นับเป็นครั้งอย่างเดียว) จะพิมพ์ตัวเลขลงในช่องกลางเลยก็ได้

   | คอลัมน์ | ความหมาย |
   |---|---|
   | **ยอดเดิม** | ยอดสะสมก่อนสัปดาห์นี้ — **พิมพ์แก้ได้** |
   | **สายสัปดาห์นี้** | กด − / + หรือพิมพ์ตัวเลข |
   | **รวมทั้งหมด** | ยอดเดิม + สัปดาห์นี้ (แถวแดง = ถึงเกณฑ์แล้ว) |

   - **เด็กที่มีสถิติเดิมในสมุดแต่ยังไม่มีในระบบ** (เช่นสายมาแล้ว 3 ครั้ง ยังไม่ถึง 4 เลยไม่มีในไฟล์ Word)
     ให้พิมพ์ **3** ลงช่องยอดเดิม แล้วกด **+** อีก 1 → รวมเป็น 4 เข้าเกณฑ์ทันที
     สัปดาห์หน้ายอดเดิมจะขึ้นเป็น 4 ให้เอง กด + อีก 1 ก็เป็น 5 ไปเรื่อย ๆ
   - ตัวเลขแดงบนปุ่มห้อง = จำนวนคนที่บันทึกไว้ในห้องนั้นของสัปดาห์นี้
   - ถ้าจำห้องไม่ได้ ใช้ช่อง **ค้นหาชื่อ** พิมพ์ชื่อได้เลย (ค้นทุกห้อง)
5. ไปแท็บ **② สรุป & พิมพ์ Word** → ตรวจตัวอย่างเอกสาร → กด
   **⬇ ดาวน์โหลด Word (.docx)** (หรือ **⬇ ทั้ง 2 ช่วงเวลา** เพื่อได้ทั้ง 07.50 และ 08.30)

ไฟล์ที่ได้จะชื่อเช่น `สรุปสาย 07.50 น. สัปดาห์ที่ 13 17-21 สิงหาคม 2569.docx`
เปิดด้วย Word แล้วสั่งพิมพ์ได้ทันที (ฟอนต์ TH SarabunPSK ขนาด/ตาราง/หัวเรื่อง/ผู้ลงนาม ตรงตามฟอร์มเดิม)

> ระบบจะใส่เฉพาะนักเรียนที่ **สาย 4 ครั้งขึ้นไป** (แก้ตัวเลขเกณฑ์ได้ที่ช่อง “เกณฑ์”)

## ตั้งค่าครั้งแรก (ทำครั้งเดียว)

### 1. ยอดยกมา — ใส่ให้แล้ว
ยอดสะสม **ถึงสัปดาห์ที่ 12** ถูกดึงจากไฟล์ Word เดิมมาใส่เป็นค่าเริ่มต้นให้แล้ว
(สาย 07.50 น. 28 คน / สาย 08.30 น. 1 คน) ตรวจดูได้ที่แท็บ **ยอดยกมา**
ถ้าต้องการโหลดใหม่ กดปุ่ม **↺ โหลดยอดสะสมถึงสัปดาห์ที่ 12**

> แท็บ **ยอดยกมา** ใช้ดู/แก้ยอดตั้งต้นทีละห้องได้ แต่ปกติแก้ที่ช่อง **ยอดเดิม** ในหน้าติ๊กได้เลย สะดวกกว่า

> นักเรียน 6 คนในเอกสารเดิมมีเลขที่/ชื่อไม่ตรงกับไฟล์ Excel ใหม่ ระบบจับคู่ด้วยชื่อให้แล้ว เช่น
> อณัญญา วงศ์จิรวัฒนกุล 10/29→10/28, กานต์ธิดา ครบรัตนะ 13/20→13/21,
> อภิสรา ทรวดทรง 13/29→13/30, ปวริศร์ฐา พงกันยา 13/30→13/31
> ส่วน 2/3 และ 2/7 สะกดชื่อต่างกันเล็กน้อย ใช้ชื่อตาม Excel ใหม่

### 2. ตรวจรายชื่อ
ไฟล์ `ม.4.xls` ใหม่มี 13 ห้อง 475 คน แต่ **ห้อง 1 มี 25 คน และ ห้อง 4 มี 15 คน** (ห้องอื่น 38–40 คน)
ถ้าไม่ครบให้เพิ่มที่แท็บ **รายชื่อนักเรียน**:
- คัดลอกจาก Excel 3 คอลัมน์ (ห้อง / เลขที่ / ชื่อ-สกุล) มาวางในกล่องข้อความ แล้วกด **เพิ่ม/อัปเดตจากข้อความ**
- หรือพิมพ์ทีละคนในช่องด้านบน

รายชื่อที่แก้จะเก็บไว้ในเบราว์เซอร์ (กด “คืนค่ารายชื่อเริ่มต้น” เพื่อกลับไปใช้ไฟล์ `students.js`)

> **ขึ้นปีการศึกษาใหม่** ให้แทนที่รายชื่อทั้งหมดจากแท็บนี้ หรือส่งไฟล์ Excel ใหม่มาให้สร้าง `students.js` ใหม่

### ถ้าเปลี่ยนไฟล์ `students.js` เป็นรายชื่อชุดใหม่
ต้องแก้เลขเวอร์ชัน **2 ที่** ให้ตรงกัน ไม่งั้นเบราว์เซอร์จะยังจำรายชื่อเก่า

| ไฟล์ | บรรทัด |
|---|---|
| `students.js` | `window.ROSTER_VERSION = "2569-1";` |
| `index.html` | `<script src="students.js?v=2569-1">` (และอีก 2 บรรทัดถัดไป) |

เปลี่ยนเป็นเลขใหม่ เช่น `2570-1` ทั้งสองที่ → โปรแกรมจะโหลดรายชื่อใหม่และ**ทิ้งรายชื่อเก่าที่เคยแก้ไว้ในเครื่องอัตโนมัติ**

### 3. ผู้ลงนาม
ตั้งไว้ 2 คน — **นายศราวุธ  พิมศร** และ **นางมานิดา ยอดเมือง**
เลือกได้จากช่อง **ผู้ลงนาม** ในแท็บสรุปก่อนกดดาวน์โหลด
แก้ชื่อ/ตำแหน่งของทั้งสองคนได้ที่แท็บ **ข้อมูล / สำรอง**
(ตอนนี้ตั้งตำแหน่งไว้เหมือนกันทั้งคู่คือ “รองหัวหน้าระดับชั้นมัธยมศึกษาปีที่ 4” — แก้ได้ตามจริง)

## ☁ ฐานข้อมูล Google Sheet (ตั้งครั้งเดียว)

ข้อมูลเก็บใน **เบราว์เซอร์เครื่องที่ใช้** (localStorage) เป็นหลัก และซิงก์ขึ้น **Google Sheet** เพื่อกันข้อมูลหาย
และให้เปิดจากเครื่องไหนก็ทำงานต่อได้

### ติดตั้ง Apps Script
1. เปิด Google Sheet ที่จะใช้เก็บข้อมูล → เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมทั้งหมด → เปิดไฟล์ **`Code.gs`** ในโฟลเดอร์นี้ คัดลอกไปวางทั้งหมด → **บันทึก**
3. **Deploy → Manage deployments → (ไอคอนดินสอ) Edit**
   - Version: **New version**
   - Execute as: **Me**
   - Who has access: **Anyone**
   - → **Deploy** (ลิงก์ `/exec` เดิมใช้ได้ต่อ ไม่ต้องแก้ในเว็บ)
4. ครั้งแรกจะขึ้นให้อนุญาตสิทธิ์ ให้กด Authorize จนจบ
   (ถ้าขึ้นเตือน “Google hasn’t verified this app” → Advanced → Go to … (unsafe) → Allow)

ชีตจะถูกสร้างให้อัตโนมัติ 4 แผ่น: **students / late / carry / meta** — เปิดดูข้อมูลดิบได้ตลอด

### ใช้งาน
| ปุ่ม | ทำอะไร |
|---|---|
| ☁ ซิงก์ (มุมขวาบน) | บันทึกข้อมูลปัจจุบันขึ้น Google Sheet |
| ⬆ บันทึกขึ้นคลาวด์ | เหมือนกัน (อยู่ในแท็บ ข้อมูล / สำรอง) |
| ⬇ ดึงจากคลาวด์ | ดึงข้อมูลจากชีตมาทับในเครื่อง (ใช้ตอนย้ายเครื่อง) |
| ส่งรายชื่อนักเรียนขึ้นชีต | เขียนรายชื่อทั้งหมดลงชีต students |
| ☑ ซิงก์อัตโนมัติหลังติ๊ก | ติ๊กเสร็จ 5 วินาที ระบบบันทึกขึ้นคลาวด์ให้เอง (เปิดไว้เป็นค่าเริ่มต้น) |

- ถ้ามีคนแก้จากอีกเครื่องพร้อมกัน ระบบจะเตือนก่อนทับ (ระบบนับ rev ให้)
- ถ้าเชื่อมต่อไม่ได้ ข้อมูลยังอยู่ในเครื่องครบ แค่กด ⬆ ใหม่ทีหลังได้
- ปุ่ม **⬇ สำรองข้อมูล (.json)** ยังใช้ได้เหมือนเดิม เก็บไฟล์ไว้อีกชั้นก็ดี
